## 研究方法论 / 迭代路径

项目按"假设 → 回测 → 证伪/证实 → 换方向"的顺序推进，每一步都是对上一步失败原因的直接回应：

```
趋势跟随/突破 (失败: 熊市无趋势)
   → 截面动量轮动 (失败: 转换损耗吃掉理论边际)
      → 截面反转 (灾难性失败: 系统性接刀)
         → 恐慌接刀 v1 (失败: 止盈止损不对称方向反了)
            → 恐慌接刀 v2 + 波动率闸门 (成功, 全历史每年为正) ─┐
      → 社区策略验证 NFI X7 (成功, 三窗口独立验证通过) ───────┼→ 双策略实盘部署
   → FreqAI/ML 四次实验 (全部阴性, 正式关闭) ─────────────────┘
```

### 关键方法论教训

1. **状态平均边际 ≠ 交易系统收益**：转换时刻（入场在涨后/出场在跌后）的损耗可以吃掉全部理论状态边际
2. **容量约束改变选择分布**：5 仓位上限 + 止损保护意外地避开了最差的那批入场
3. **数据窗口偏差**：截断的数据窗口（缺失某段熊市绞杀期）曾把 +0.4%/笔 美化成 +2.7%/笔；`freqtrade download-data` 默认增量追加，回填历史必须显式 `--prepend`
4. **胜率无意义**：86% 胜率照样能亏钱；只看 期望收益 × 频率 vs 成本 × 换手率才有意义
5. **回测三件套**：`--fee`、`--enable-protections`、训练/保留期严格分离才算数
6. **事件级均值 ≠ 系统级收益**：事件网格显示"宽出场"单笔均值更高，但在组合复利/槽位占用动态下系统级风险调整后收益反而更差（PanicPounce2 vs PanicPounce2Wide A/B，见下文）

## 幸存者 A：PanicPounce2（自研）

恐慌接刀策略，核心洞察来自对失败的 v1 和大量事件网格的复盘：**alpha 衰减发生在"普通恐慌"区间（BTC 7 日年化波动率 40-50%），但极端崩盘区间（≥50%）的流动性提供溢价至今仍然存活**——程序化做市资金在极端时刻也会撤单，竞争在那个瞬间消失。

- **入场**：`24h 收益率 < -10% AND 收盘价 < 布林带下轨 AND BTC 7 日年化波动率 ≥ 50%`
- **出场**：10% 止盈 / 5% 止损 / 36 小时强制离场（`minimal_roi: {"0": 0.10, "2160": -1}`, `stoploss: -0.05`）
- **保护**：CooldownPeriod（4 根 K 线）+ StoplossGuard（48 根回看窗口，5 笔触发，冷却 12 根）
- 闸门阈值在 40/50/55 三个取值上都稳健为正，非单点过拟合

**分层验证过程**（组合重放 → freqtrade 全引擎回测）：

| 闸门 | 2023 | 2024 | 2025 | 2026 | 单笔均值 | 胜率 |
|---|---|---|---|---|---|---|
| vol≥40 | +48.9% | +43.4% | +16.7% | **-5.9%** | +1.00% | 49.7% |
| vol≥50（部署版） | +11.0% | +66.8% | +13.1% | **+17.5%** | +1.92% | 55.8% |
| vol≥55 | +7.7% | +46.3% | +5.9% | **+19.1%** | +2.08% | 55.6% |

freqtrade 全引擎回测（gate50，`--enable-protections`，fee 0.1%）：
- 2023-03~2026-08 全历史：**+47.6%（CAGR 11.9%）**，263 笔，单笔均值 +0.87%，胜率 47.1%，钱包最大浮亏 22.6%
- 2026-01~2026-08：+1.25%（同期市场 -27.97%），34 笔，浮亏 10.5%

**出场参数 A/B 终审**：事件网格显示宽出场（15%/8%/72h）单笔均值更高（+2.56% vs +1.31%），但 freqtrade 系统级回测显示宽版浮亏扩大到 32.9%（窄版 22.6%）而总收益基本持平——事件级优势被槽位占用与复利动态吃掉。结论：部署窄出场版本。

## 已关闭分支：FreqAI / TaffyML

四次独立实验，结论一致且因果链清晰，作为项目最有信息量的阴性结果记录在案：

| 版本 | 改动 | 结果 |
|---|---|---|
| v1 | 回归标签，90 天训练窗 | 2026-06 单月 -20.4%，训练窗无崩盘样本，纯粹拿了市场 beta |
| v2 | 训练窗拉长到 365 天 + EMA200 趋势闸门 + 入场阈值 1.0% | -29.1%；出场分解：`ml_flip` 累计 +31.2%（模型有方向信号），但 `stop_loss` 累计 -65.2%（79 笔 0% 胜率）——固定 -5% 硬止损与 12h 预测尺度错配，474 笔交易的手续费又吃掉约 19% 钱包 |
| v3a | 止损放宽到 -10%，验证是否是出场参数的问题 | -33.7%，更差 —— 证明病灶是入场信号本身，不是出场校准 |
| v3b | 绕开 FreqAI 管线，直接用 LightGBM 在 1316 个手工提取的恐慌事件上训练分类器，按年步进验证 | 2025 折 AUC 0.547（模型 top50% 反而跑输手工 gate50 规则）；2026 折 AUC 0.352 —— 比随机还差且方向反转（模型看好的 top30% 实际 -3.2%，看衰的 bottom50% 反而 +1.3%） |

**结论**：在这个非平稳、被程序化资金快速磨平的市场里，拟合的复杂形态比结构性规则衰减更快。手工构造的 vol≥50 闸门规则在两个纯样本外年份都稳定跑赢 ML 模型。ML 分支正式关闭，不再投入算力，除非未来出现能明确解释这一反转的新证据。

## 复现方法

所有分析脚本均设计为在 `freqtradeorg/freqtrade:stable`（或 `:stable_freqai`）容器内以独立 Python 脚本方式运行，避免在宿主机安装 pandas/pyarrow 等依赖：

```bash
docker run --rm -v $(pwd)/analysis:/scripts -v <data_dir>:/freqtrade/user_data/data \
  --entrypoint python3 freqtradeorg/freqtrade:stable /scripts/portfolio_replay.py
```

策略回测（以 PanicPounce2 为例）：

```bash
freqtrade backtesting \
  --config freqtrade/bt_config.json \
  --strategy PanicPounce2 \
  --timerange 20230301-20260819 \
  --enable-protections
```

## 诚实声明

- 所有结果均为历史回测 / dry-run 模拟，不构成投资建议；本项目全程未使用真实资金
- PanicPounce2 的 vol≥50 闸门样本量随阈值提高而收缩，极端行情事件本身historically 稀缺，需持续用样本外数据验证是否稳健
- 2026 年段多数策略（含 PanicPounce2 早期版本）表现明显弱于 2023-2025，观察到的"程序化资金磨平短线机会"是本项目对该现象的一种解释，非唯一可能解释
- NostalgiaForInfinityX7 为第三方社区策略，本项目仅做独立验证，不对其长期表现做任何保证
- FreqAI/ML 分支的阴性结果基于本项目采用的特征集、标签定义与训练窗口设置，不构成"ML 在加密短线交易中必然无效"的一般性结论
